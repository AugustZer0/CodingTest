# 재귀(DFS) 인자 정리: DFS(0), DFS(1), DFS(0, 0)는 언제 쓰나

> 핵심: **DFS의 인자 = 다음 단계로 넘겨야 하는 정보**
> 두 가지만 보면 된다.
> 1. **인자 개수**: 무엇을 기억해야 하나?
> 2. **시작 값 (0 / 1)**: 인덱스를 0부터 쓰나, 1부터 쓰나?

---

## 1. 인자 개수: "무엇을 기억해야 하나?"

| 인자 | 의미 | 언제 필요한가 |
|---|---|---|
| `L` | 지금 몇 번째 자리를 정하는 중인가 (깊이) | **항상** |
| `s` | 이번 자리에서 어떤 수부터 고를 수 있나 | for문이 처음부터 돌면 안 될 때 (**조합**) |
| `sum`, `cnt` 등 | 지금까지 쌓인 값 | 합, 개수 같은 값을 들고 다니거나 가지치기를 할 때 |

### `s`가 필요한지 판단하는 기준: for문

- **매번 처음(1)부터 돌아도 된다** → `DFS(L)` (중복순열, 순열)
- **앞에서 고른 수 다음부터 돌아야 한다** → `DFS(L, s)` (조합)

> 조합에서 `(1, 2)`를 골랐으면 `(2, 1)`은 다시 고르면 안 된다.
> 그래서 "다음엔 어디서부터 고를지"를 `s`로 넘긴다.

---

## 2. 0부터인가 1부터인가: "인덱스를 어떻게 쓰나?"

시작 값과 종료 조건은 **항상 짝**으로 움직인다.

| 시작 | 의미 | 종료 조건 |
|---|---|---|
| `DFS(0)` | 0개 정해짐 (`res[0]`부터 채움) | `L == m` 또는 `L == n` |
| `DFS(1)` | 1번 원소부터 결정 (1-based `ch[1..n]`) | `L == n + 1` |

`s`도 같은 방식이다.

| 고르는 대상 | 시작 | for문 |
|---|---|---|
| 숫자 `1 ~ n` | `s = 1` | `range(s, n + 1)` |
| 리스트 `a` | `s = 0` | `range(s, len(a))` |

> ✅ `DFS(0)`과 `DFS(1)`의 차이는 **인덱스를 0부터 쓰는지 1부터 쓰는지일 뿐**이고, 로직은 같다.
> 하나로 통일하면 헷갈릴 일이 줄어든다. **0-based로 통일하는 것을 추천한다.**

---

## 3. 유형별 틀 (0-based로 통일)

### 3-1. 부분집합: `DFS(L)`

L번째 원소를 **넣을지 말지** 정한다. for문 없이 갈래가 두 개다.

```python
def DFS(L):
    if L == n:
        # ch[i] == 1인 원소들이 부분집합
        return
    ch[L] = 1; DFS(L + 1)   # 넣는다
    ch[L] = 0; DFS(L + 1)   # 안 넣는다

DFS(0)
```

### 3-2. 중복순열: `DFS(L)`

매번 **처음부터 다** 고를 수 있다.

```python
def DFS(L):
    if L == m:
        print(res); return
    for i in range(1, n + 1):
        res[L] = i
        DFS(L + 1)

DFS(0)
```

### 3-3. 순열: `DFS(L)` + `ch`

처음부터 돌되, **이미 쓴 수만 건너뛴다.**

```python
def DFS(L):
    if L == m:
        print(res); return
    for i in range(1, n + 1):
        if ch[i] == 0:
            ch[i] = 1
            res[L] = i
            DFS(L + 1)
            ch[i] = 0          # 되돌리기 (백트래킹)

DFS(0)
```

### 3-4. 조합: `DFS(L, s)`

**고른 수 다음부터만** 본다.

```python
def DFS(L, s):
    if L == m:
        print(res); return
    for i in range(s, n + 1):
        res[L] = i
        DFS(L + 1, i + 1)      # 중복조합이면 i

DFS(0, 1)   # 0개 골랐고, 1부터 고를 수 있음
```

### 3-5. 합 문제 (예: 부분집합의 합이 같은지): `DFS(L, sum)`

부분집합 구조에 **값을 들고 다니는** 인자를 추가한다.

```python
def DFS(L, sum):
    if sum > total // 2: return   # 가지치기
    if L == n:
        ...; return
    DFS(L + 1, sum + a[L])        # a[L]을 포함
    DFS(L + 1, sum)               # a[L]을 포함 안 함

DFS(0, 0)
```

## 4. 한눈에 비교

| 유형 | 호출 | for문 범위 | 다음 호출 | 체크 배열 |
|---|---|---|---|---|
| 부분집합 | `DFS(0)` | 없음 (넣는다 / 안 넣는다) | `DFS(L+1)` × 2 | `ch[L]` (포함 여부) |
| 중복순열 | `DFS(0)` | `range(1, n+1)` | `DFS(L+1)` | ❌ |
| 순열 | `DFS(0)` | `range(1, n+1)` | `DFS(L+1)` | ✅ `ch[i]` (사용 여부) |
| 조합 | `DFS(0, 1)` | `range(s, n+1)` | `DFS(L+1, i+1)` | ❌ |
| 중복조합 | `DFS(0, 1)` | `range(s, n+1)` | `DFS(L+1, i)` | ❌ |
| 합 문제 | `DFS(0, 0)` | 없음 | `DFS(L+1, sum+a[L])`, `DFS(L+1, sum)` | ❌ |

---

## 5. 문제 풀 때 순서

1. **무엇을 고르는가?** 원소 하나하나를 넣을지 말지 정하면 **부분집합형**, 자리마다 수를 뽑으면 **순열/조합형**
2. **순서가 중요한가?** 중요하면 순열(`DFS(L)`), 중요하지 않으면 조합(`DFS(L, s)`)
3. **같은 수를 또 써도 되나?** 안 되면 순열은 `ch`를 쓰고, 조합은 `i + 1`을 넘긴다. 되면 `ch` 없이 쓰고, 조합은 `i`를 넘긴다.
4. **들고 다닐 값이 있나?** 합, 개수 등이 있으면 인자를 추가한다 (`sum` 등).
5. **시작 값과 종료 조건을 짝으로 맞춘다.** `DFS(0)`이면 `L == n`, `DFS(1)`이면 `L == n + 1`

## 한 줄 요약

| 무엇을 | 어떻게 |
|---|---|
| 인자 개수 | 깊이 `L`은 항상 쓰고, 고른 수 다음부터 골라야 하면 `s`, 값을 들고 다녀야 하면 `sum`을 추가한다 |
| 0 / 1 | 인덱스를 0부터 쓰는지 1부터 쓰는지일 뿐이다. 시작 값과 종료 조건을 짝으로 맞춘다 |
