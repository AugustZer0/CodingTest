# 이분탐색 (결정 문제) 접근법

> 핵심: **답 자체를 lt ~ rt 범위에 놓고 이분탐색한다.**
> mid가 답이 될 수 있는지(feasible)를 확인하면서 범위를 좁힌다.

---

## 1. 구하는 게 무엇인지 정확히 파악 (길이, 용량, 개수, 시간, 거리 ...)

- **1-1.** 구하는 값에 lt, rt를 둔다.
  - 길이를 구하면 길이에 lt, rt를 두고, 용량을 구하면 용량에 둔다.
- **1-2.** lt와 rt의 범위를 제대로 잡아야 한다. 하한이 0이나 1이 아닐 수 있다.

| 문제 | lt | rt |
|---|---|---|
| 랜선 자르기 | `1` | `max(랜선)` |
| 뮤직비디오 | `max(곡 길이)` ← 한 곡은 무조건 들어가야 함 | `sum(곡 길이)` |
| 마구간 정하기 | `1` | `max(좌표) - min(좌표)` |
| 입국심사 | `1` | `min(심사시간) * n` |

---

## 2. if 조건 정하기: "mid가 문제를 만족하는가?"

**부등호(`>=` / `<=`)는 외우지 않는다.** Count가 무엇을 세는지 보고 매번 정한다.

### 정하는 방법

**질문 1. "mid로 Count를 구했을 때, 만족한다는 건 무슨 뜻이지?"** (문장으로 써 보기)

- 랜선: 길이 mid로 잘라서 **N개 이상** 나오면 됨 → `Count(mid) >= n`
- 뮤직비디오: 용량 mid로 담아서 **DVD M장 이하**로 들어가면 됨 → `Count(mid) <= m`
- 마구간: 거리 mid 이상 간격으로 **C마리 이상** 배치할 수 있으면 됨 → `Count(mid) >= c`
- 입국심사: mid 시간 동안 **N명 이상** 처리하면 됨 → `Count(mid) >= n`

**질문 2. (확인용) "mid가 커지면 만족하기 쉬워지나, 어려워지나?"**

- 쉬워짐 (용량, 시간 ...) → 보통 **최소** 문제
- 어려워짐 (자르는 길이, 거리 ...) → 보통 **최대** 문제
- 질문 2의 답이 문제가 묻는 최대/최소와 맞으면, 질문 1의 조건을 맞게 세운 것이다.

### 부등호와 최대/최소는 서로 독립이다

|  | `Count >= ?` | `Count <= ?` |
|---|---|---|
| **최대** | 랜선 자르기, 마구간 정하기 | (가능) |
| **최소** | **입국심사** ⚠️ | 뮤직비디오 |

> ⚠️ "최대면 `>=`, 최소면 `<=`"는 **틀린 공식**이다. 입국심사는 최소를 구하는데 조건이 `>=`다.

---

## 3. 최대인지 최소인지 파악: 이동 방향 (이건 외운다)

`while lt <= rt:`로 시작한다.

> 외울 것: **만족하면 res = mid로 저장하고, 원하는 방향으로 더 가 본다.**
> - 최대 → 만족하면 오른쪽으로 (`lt = mid + 1`)
> - 최소 → 만족하면 왼쪽으로 (`rt = mid - 1`)

### 3-1. 최대일 경우

```python
res = -float('inf')        # 답이 항상 있으면 0이어도 됨
while lt <= rt:
    mid = (lt + rt) // 2
    if 만족(mid):          # 예) Count(mid) >= m  ← 부등호는 2번에서 정함
        res = mid
        lt = mid + 1       # 더 큰 값도 되는지 확인
    else:
        rt = mid - 1
```

### 3-2. 최소일 경우

```python
res = float('inf')
while lt <= rt:
    mid = (lt + rt) // 2
    if 만족(mid):          # 예) Count(mid) <= m  또는  Count(mid) >= n (입국심사)
        res = mid
        rt = mid - 1       # 더 작은 값도 되는지 확인
    else:
        lt = mid + 1
```

### 예시: 입국심사 (최소인데 `>=`)

```python
if Count(mid) >= n:   # 부등호: Count가 "처리한 인원"이니까 >=
    res = mid
    rt = mid - 1      # 이동: 최소를 구하니까 왼쪽으로
else:
    lt = mid + 1
```

---

## 4. lt, rt 갱신 규칙

대부분의 이분탐색에서 lt, rt는 다음과 같이 갱신한다.

```python
lt = mid + 1
rt = mid - 1
```

- 반드시 **`while lt <= rt`와 짝으로** 쓴다.
- `<`로 쓰면 lt == rt인 마지막 값을 검사하지 않고 지나친다.

## 한 줄 요약

| 무엇을 | 어떻게 |
|---|---|
| lt, rt 범위 | 구하는 값의 실제 범위로 잡는다 (하한 주의) |
| if 부등호 | **외우지 않는다.** "만족 = ?"을 문장으로 쓰고 정한다 |
| 이동 방향 | **외운다.** 만족하면 res 저장, 최대는 `lt = mid + 1`, 최소는 `rt = mid - 1` |
| 루프 | `while lt <= rt` + `mid ± 1` |
